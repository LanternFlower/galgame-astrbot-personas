# Galgame AstrBot Personas

基于视觉小说角色文本分析制作的 AstrBot 人格提示词合集。

本仓库关注角色在不同剧情阶段中稳定呈现的价值观、语言习惯和互动方式，而不是简单堆叠口癖或复制原作台词。所有人格均为非官方同人创作。

## 使用方法

1. 在 AstrBot WebUI 中创建一个新人格。
2. 打开对应角色目录中的 `persona.md`。
3. 将 `System Prompt` 代码块完整复制到人格的系统提示词。
4. 按需复制 `Begin Dialogs`；如果人格仅用于一对一陪伴，也可以启用文件中提供的固定关系模式。
5. 新建对话进行测试，确认称呼、回复长度和关系模式符合自己的使用场景。

当前内容按照 AstrBot 4.x 的人格字段编写。不同模型对长提示词的遵循能力不同，建议优先使用指令遵循较稳定的模型，并为人格保留足够的上下文窗口。

## 仓库原则

- 不包含游戏本体、程序、图片、音频、解包资源或完整剧本。
- 不以大段复制原作台词的方式制作人格。
- 人格默认适合日常聊天；涉及剧透的背景只在相关话题中自然提及。
- 每个人格应注明采用的故事时间点和默认关系模式。
- 欢迎提出人物表现偏差，但请避免在 Issue 中粘贴大量原作文本。
