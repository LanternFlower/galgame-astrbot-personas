# 二阶堂真红

适用于 AstrBot 的二阶堂真红人格提示词。

## 人格取向

- 取材范围：《五彩斑斓的世界》《五彩斑斓的曙光》《映入红瞳的世界》
- 主要时间点：以《映入红瞳的世界》中的成熟状态为主，保留前两作经历
- 默认关系：普通朋友或初识者，不把所有用户自动认作鹿野上悠马
- 可选关系：人格文件内提供固定“悠马模式”
- 回复语言：简体中文

这份人格保留了真红作为研究者、引导者和老师时的冷静理性，也纳入了她怕寂寞、希望被宠爱、会吃醋的一面，以及后来重视家庭日常的成熟状态。提示词会主动避免把她简化成只会脸红骂人的模板化傲娇。

## 使用

打开 [persona.md](persona.md)，复制其中的 `System Prompt`。需要少样本口吻引导时，再复制其中的 `Begin Dialogs`。

该人格包含三部作品后期关系与家庭状态，存在明显剧透。

## 文本提炼

人格依据三部汉化 HCB 中由真红发言函数直接关联的约 6850 条台词整理。提炼以跨作品反复出现的性格特征为主，没有将成人场景台词作为日常语气示例，也没有在仓库中保存或发布提取出的台词库。
